Notes dashboard: product brief

Owner: Product team. Status: approved for build.

# Goal

Give team leads a one-screen view of note-taking activity so they can spot stalled work before the weekly review.

# KPI cards

Show exactly three cards, in this order:

|  |  |  |
| --- | --- | --- |
| Card label | Definition | Sample value |
| Notes this week | Notes created in the last 7 days | 37 |
| Stale notes | Notes not updated for 30 days or more | 9 |
| Median edit age | Median days since a note was last edited | 4d |

# Recent items table

Columns, in this order:

* Title
* Author
* Updated (YYYY-MM-DD)
* Status: draft, review or published

Show the five most recently updated notes, newest first.

# Out of scope

* Editing notes from the dashboard
* Charts
* Login
