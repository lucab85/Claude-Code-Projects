# Stack (ch07 only)
- Flask is the only runtime dependency in this folder.
- Playwright is a dev tool for screenshots; never import it in app.py.
- Plain CSS in static/styles.css. No Tailwind, no CSS frameworks.

# Commands
- Run the app:     python3 app.py  (serves http://localhost:5001)
- Screenshot it:   python3 shot.py http://localhost:5001 render.png
